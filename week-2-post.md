### [Machine Learning Research]

**Explain AT LEAST TWO of the seven steps of Machine Learning as you would explain to a friend that knows nothing about Machine Learning:**
- The seven steps of Machine Learning are:
1. Gathering Data
2.	Preparing that data
3.	Choosing a model
4.	Training
5.	Evaluation
6.	Hyperparameter Tuning
7.	Prediction
- The two steps I will focus on are **Gathering Data** and **Training** because collecting quality data directly impacts how well the model can learn patterns and relationships during training:
  1.	Gathering Data - Think of data as collecting bits of information from various sources to help to train the model. These bits of information are relevant to what we want the model to learn. For example, if we want the model to identify cat and dog in photos, we will then need a diverse collection of photos. The quality and quantity of the data gathered has a significant impact on how effective the machine learning model is
  2.	Training - Training is the process of teaching the model using the prepared data. The model is presented with data and learns any patterns and relationships. This is like how a dog might be trained by showing the dog what to do and giving treats when the action is correct

**An application of Machine Learning that I discovered while researching is Fraud Detection.**

**How does Machine Learning improve or replace existing solutions?**
- Machine Learning helps to improve existing solutions by using large datasets and advanced algorithms to identify patterns and any anomalies that indicate fraudulent behavior, which makes it possible to detect and prevent fraud in real-time. Machine Learning makes Fraud Detection fast, able to be scaled with additional data, efficient and more accurate.

**Is the application in development or actively being used by companies/institutions?**
- Fraud Detection and Machine Learning are actively being used by companies/institutions. With the increasing number of online transactions, needing to identify and prevent fraudulent activities is increasingly important. Companies across many sectors are using technologies like Machine Learning to detect and prevent fraud. Some of these sectors are the financial, government, insurance and the retail sector

**Describe AT LEAST ONE ethical concern using Machine Learning for this application?**
- There is a need to delicately balance between enhancing security and respecting the user’s privacy when using Machine Learning in Fraud Detection. Organizations must make sure to protect the individual’s privacy. Machine Learning to detect fraud requires vast amounts of personal data for training and analysis purposes. Anonymizing the data and taking protection measures and preserving the privacy of the data can help organizations protect the privacy of individuals
